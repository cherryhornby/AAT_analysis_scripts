# A collection of python scripts used in the analysis of MD ensembles of AAT

This repository contains the python scripts and data used for a several analyses of the molecular dynamics ensembles of alpha-1-antitrypsin (AAT) in isolation, monomeric ribosome-nascent chain complex and co-translational-post-translational (co-post) complex.

These analyses include:
* bootstrapped free energy profiles to assess convergence
* pairwise contact probability calculation
* coordination number calculation between sidechain COMs
* ensemble prediction of protection factors for comparison/reweighting with PEGylation rates
* extraction of ensemble frames as substates from the ELViM projection's free energy surface

## Scripts

### `inter_pairwise_contact_prob_calc.py`

Calculates the intermolecular pairwise contact proability between two molecules (e.g. nascent AAT and post-translational AAT) and returns a square matrix of the contact probabilities.

### `pairwise_contact_prob_calc.py`

Calculates the intramolecular pairwise contact probability and returns a square matrix of the contact probabilities. Also computes the normalised sum contact probability within the ensemble and can have minimum and maximum sum probability set to have cross comparison across ensembles.

### `extract_substates_from_elvim_contours.py`

Plots the free energy surface based on the projection ELViM output from an ensemble and then using the contours plotted generates a polygon mask to select frames from indices of the ELViM projection within the contours of the lowest free energy minima (e.g. < 1 kj/mol).

Returns frames in a .ndx file for extraction from ensemble and downstream analysis as substates. 

### `calc_fep_bootstrap_rmsd.py`

Performs the block bootstrap procedure on an ensemble by portioning a trajectory into contiguous blocks of length exceeding the integrated autocorrelation time of the CV (Q), ensuring that block averages were approximately uncorrelated. Bootstrap replicas were then generated by resampling these blocks with replacement and recomputing the weighted histograms of Q. Free energy profiles of the bootstrapped histograms are then compared to the reference profile of the full trajectory using RMSD. RMSD to the final profile plotted as function of trajectory length is plotted and can be used to assess convergence.

### `calc_contact_number_4_PEG_PFs.py`

Computes from an ensemble the number of calphas within a cutoff radius to a PEGYlation probe site and calculated the ln(PF) due to the approxination of the phenomenological expression: ln(PF) = a<sub>C</sub>N<sub>C</sub> (_Best, R.B., et al. Structure. 2006_).

### `calc_sc_coord_num.py`

Calculates for each residue the side chain coordination number using centre of masses (COMs) and a smooth switching function rather than a hard cutoff. The script excludes same residue and the immediate sequence neighbour in the calculations and handles glycine by using the calpha atom as its sidechain.

## Software requirements

The analyses scripts were performed in Python 3.11 and relevant packages can be found in the import modules section of each code.
